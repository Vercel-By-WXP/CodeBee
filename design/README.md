# CodeBee 界面重构 · Demo

> 不是重画五个页面，是把「页面自己定义外观」这件事禁掉。

打开方式（必须用 http，不要双击 file://，iframe 会受限）：

```bash
cd design/demo
py -3.13 -m http.server 18801 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:18801/
```

展厅左侧切换五个视图，顶部切明暗与宽度（桌面 1440 / 窄屏 1024 / 手机 390），
明暗开关会同步到所有场景，用来验证「同一套形状语言在两种底色下都成立」。

## 二、三层结构

```
tokens.css      决定「长什么样」—— 颜色、字阶、间距、圆角、阴影、动效、骨架尺寸
components.css  决定「怎么用」  —— 按钮、输入、标签、表格、空态、进度、列表项
pages/*.html    只写布局      —— 不允许出现色值和写死的字号
```

**两条铁律**（违反任何一条，四个场景会重新分叉）：

1. 页面里不写颜色、不写 px 字号、不写圆角，一律 `var(--*)`。
2. 觉得「这个按钮应该不太一样」→ 改 `components.css`，不许在页面里覆盖。

## 三、两套底色，一套形状

`data-surface="paper"` 暖纸底，写作与阅读场景默认；`data-surface="ink"` 暖黑底，盯屏场景默认。

**只有颜色变量跟着换，间距、圆角、字阶、控件高度、动效曲线全部不变。**
所以小说版和成稿台在暗色下依然「像同一个产品」，而不是变成另一个产品。

### 强调色为什么从朱砂换成了墨青

第一版用朱砂 `#a8481f`，结果和危险色 `#a32f27` 色相只差 8°——
「正在评审」和「废标风险」在色板上几乎不可分辨，这是语义 bug，不只是审美问题。

现在：

| 角色 | paper | ink | 用途 |
|---|---|---|---|
| `--accent` | `#1f5a63` 墨青 | `#6fb3be` | **只表示「正在进行 / 需要看这里」** |
| `--ok` | `#2c6a4a` | `#6cc08d` | 通过、已具备 |
| `--warn` | `#97600a` | `#d9a03f` | 待补、未过线 |
| `--bad` | `#a32f27` | `#e07a6e` | 废标、失败 |

主按钮不用强调色，用近黑（亮底）/ 近白（暗底）。这样工程界面不轻浮，写作界面不刺眼，
强调色也保住了「只标状态」的唯一语义。

## 五、迁移到真实页面（按风险从低到高）

| 步骤 | 做什么 | 影响面 |
|---|---|---|
| 1 | 把 `tokens.css` 接进现有五套 CSS，先把同名变量映射到新 token（`--paper`→`--bg`、`--ink-2`→`--text-2`…），HTML 一行不动 | 只改 CSS 顶部变量块，当天可见，风险最低 |
| 2 | 用 `components.css` 替换各页按钮/输入/标签/表格，删掉重复实现 | 逐页替换，可一页一页上 |
| 3 | 统一骨架：顶栏 56、侧栏 248、右侧栏 300、页面留白 32。小说版与成稿台从全屏自由布局改为同一套骨架 | 这两页 HTML 骨架要改，视觉变化最大 |
| 4 | 设置从 `index.html` 抽成独立 `settings.html`，四个场景右上角都指向它 | 顺带补上「垂直版没有设置入口」这个硬缺口 |
| 5 | 主界面 `style.css`（9,891 行）最后动 | 最大、测试最多，等前三步稳了再收 |

第 1 步的关键是**不动结构只换变量**——能立刻让五个页面「颜色统一」，但不解决圆角与字号分叉；
第 3 步才是真正的形状统一。这也是为什么建议分两次上线。

## 六、这份 demo 没做的事（诚实记录）

- **没有接后端**。所有数据是写在 HTML 里的假数据，只为验证版式与密度。
- **设置页没画**。18 个子页是独立的活，建议单独做 `settings.html`，不塞进这次重构。
- **移动端只做了宽度约束**（390 宽不塌），没有做专门的移动布局与手势。
- **主界面没重画**。`index.html` + `style.css` + `app.js` 体量太大（近 3 万行），
  必须等 token 层先在四个小页面上验证过一轮，再动它。
- **动效只做了最必要的**（顶栏进度条、列表悬停、卡片抬升、骨架屏）。
  没有做页面转场，因为四个场景是整页跳转，转场会增加等待感。
