# 世界观设定一致性台账守则（市场包）

适用：连载与长篇的设定管理。吃书（前后矛盾）是长篇差评第一来源，且几乎全部
源于**「没有台账」而不是「记性差」**——几十万字跨度下，任何人都记不住自己写过的
每个数字与专名。本包给出一套零工具依赖的台账纪律。

## 一、台账五件套（开书第一天建立，一个文件即可）
1. **规则体系**：力量 / 能力等级、代价与限制、禁忌（什么绝对做不到）。
   **限制比能力更重要**——能赢只是爽，不能做什么才产生剧情。
2. **地理与组织**：地名 / 势力名清单（含从属关系）。一地一名，写法逐字固定
   （定了「云州」就不能又写「云洲」）。
3. **时间线**：故事内历法 + 大事件年表（含「现在」的锚点日期）；每章推进了
   多长时间记一笔，跨章对表。
4. **专有名词表**：自造词、称谓、咒语、物品名，逐字锁定。
5. **数字台账**：金额、距离、年龄、队伍人数、库存——正文出现过的每个数字。
   数字是最容易吃书的类别，因为最枯燥、最没人记。

## 二、铁律
- **设定一经正文确认，不可静默更改。**要改，走三步：登记「改了什么 / 从哪章起
  生效」→ 排查并修订前文旧描述（或用剧情解释）→ 更新台账。三步缺一不可。
- 设定揭示分层：世界观全貌不必第一章交底，但**已揭示的部分永不反悔**。
  未揭示的可以随时丰富——区分「未揭示」与「矛盾」：读者无从知晓的不算吃书。
- 新设定入正文前先对台账查重：与既有规则冲突吗？冲突就要么改新、要么改旧，
  不许「先写上再说」。
- 跨书 / 跨卷沿用设定时，以台账为准重读一遍，不凭上一本的记忆。

## 三、高频吃书场景（评审时重点排查）
- 时间线对不上：上一段还是「昨天」，三天后又被称作「昨天」；旅程三天的两头
  都只过了一夜。
- 能力凭空升级 / 降级：前面明确做不到的事，后面无解释做到了（或反之）。
- 称谓漂移：同一人物 / 势力的称呼前后不一；称呼随剧情需要临时变化。
- 死人复活 / 物品复用：已确认死亡的角色、已消耗或损毁的物品再次登场。
- 年龄与亲缘错位：年龄推算矛盾、辈分关系前后颠倒。

## 四、闭环纪律：章前查、章后记
- **章前查**：写 / 审每一章前，读一遍本章涉及的台账条目（出场地名、势力、规则、
  上次时间锚点）。30 秒的事，防 30 万字后的大返工。
- **章后记**：本章产生的任何新设定、新专名、新数字、时间推进，**当章写入台账，
  不过夜**。攒三章再补 = 必漏。
- 一致性评审给出的矛盾项，当轮修复并回填台账；同类矛盾出现第二次 = 台账结构
  要补一类条目，而不是「下次更小心一点」。

## 五、台账文件模板（可直接复制）
> ## 规则体系
> - 等级：……；代价：……；禁忌（绝对做不到的事）：……
> ## 地理与组织
> - 云州（州）＞ 落霞城（城）；青岚宗（宗门，驻落霞城）
> ## 时间线
> - 第 1 章：启程日（春三月初七）；第 2 章：+3 日 → 三月十一
> ## 专有名词表
> - 破妄瞳（术法名，逐字锁定）；称「宗主」不写「掌门」
> ## 数字台账
> - 主角 16 岁；启程盘缠 3 两银；落霞城至云州城 700 里

## 六、交稿前自检
- [ ] 本章新设定已查重并入台账，未与既有规则冲突
- [ ] 时间推进已记账，与上一章锚点衔接无误
- [ ] 数字（金额 / 距离 / 人数 / 年龄）与台账一致，新数字已登记
- [ ] 专名写法与名词表逐字一致
- [ ] 若改过既有设定：三步流程（登记 / 排查前文 / 更新台账）已走完
