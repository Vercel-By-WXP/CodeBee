# 短剧剧本支持

CodeBee 当前支持短剧的文本开发与评审，不是短剧视频生成器。

## 当前工作流

选择「短剧剧本」后，可填写集数和单集目标时长，也可以直接写在任务目标里。自动模式会先生成编排大纲，再由两名评审者检查剧本；交付包括项目圣经、角色/场景表、分集大纲和逐场剧本，并关注人物连续性、可拍性、对白和集尾钩子。集数限制为 1–200，单集时长限制为 15–600 秒；留空则由模型按任务描述判断。

成品是工作目录中的 Markdown 剧本文档。当前不生成角色/场景图片、分镜图、视频提示词、配音或最终视频，也不会调用付费媒体生成服务。

## 借鉴与边界

- [zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills)（MIT）展示了分阶段文档、跨镜连续性锁和“预览并确认后再生产”的做法。本项目采用剧本/圣经/分集结构与明确的阶段边界；尚未复制其技能文件或媒体生产工具。
- [chatfire-AI/huobao-drama](https://github.com/chatfire-AI/huobao-drama) 是端到端平台，覆盖文本、图像、视频和合成，但其仓库标注 CC BY-NC-SA 4.0。这里只参考能力分层，不复制代码；其非商业许可也不适合作为本项目可直接复用的实现来源。
- [calesthio/OpenMontage](https://github.com/calesthio/OpenMontage) 提供 agentic 视频制作管线参考。它适合作为以后媒体阶段的架构调研对象，不代表 CodeBee 当前已有视频生产能力。

## 后续扩展

若要从剧本走到成片，应另行设计分阶段资产与分镜文档、可审计的连续性检查、逐批成本/参数预览及用户确认门，再接可替换的图像/视频/配音 adapter。生成前确认和预算上限应先于自动化批量生产。
