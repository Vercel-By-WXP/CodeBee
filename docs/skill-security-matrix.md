**已知边界（如实记录，不假装覆盖）**：
- 内容扫描是静态正则，混淆变形（分段 base64、同义改写）不能保证全捕获——
  高风险确认制 + 升级突变对账是行为层兜底；
- 插件「运行期」行为（装了的技能实际诱导模型做了什么）靠评测台 Red-team
  维度（0928 二波 #2 项）与经验库启停兜底，静态扫描管不到；
- 六源中远端源的 sha256 依赖提供方 manifest，无哈希来源显示「unverified」。
