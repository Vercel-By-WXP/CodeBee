## 二、差量盘点（「他们有、我们没有」逐项核实）

**查了但已经覆盖的（不要再立项）**：上下文三段压缩（compaction.py）、单次运行 token 预算熔断（budget.max_tokens_per_run）、密钥环境变量剥离（env_scrub.py）、健康诊断（diagnostics/health）、暂停/放行（set_paused+轮间闸门）、编排者计划拆解与降级（planner.py）、经验召回注入（skills.relevance_top）、评审 rubric/轮数/阈值、跨壳失败换将、失败败率记忆、验收命令 verify_command。

**确认的真差量（按价值×大小排序，交每日自动化接力）**：
1. **Best-of-N 候选并发择优**（munder-difflin/oh-my-claudecode）：起草/实现步并发 N 个候选，评审官选优继承。价值高、改动中等（pipeline 步骤执行层）。
2. **Webhook 外部触发**：带令牌的 `POST /api/hooks/run`，让外部脚本/快捷指令开任务。价值中、改动小。
3. **任务提示词版本化**（agent-orchestrator 的 .spec/PROMPT.md 文件化）：目标+上下文可版本回溯。价值中、改动中。
4. **PR 创建按钮**（git 工作台直接 gh pr create）：依赖 gh CLI，缺省优雅降级。价值中低。
