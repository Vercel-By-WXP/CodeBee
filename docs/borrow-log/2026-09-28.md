# 2026-09-28 全类型竞品调研与七专项巡检

> 本轮在独立工作树执行，轮换池按 03 点 `% 7 = 3` 采用批 3（计划/spec/长任务）作为重点，并复查固定项目、雷达源和近期增量。主工作树存在外部未提交改动，本轮未触碰、未暂存。

## 一、调研范围与新认知

- 固定项目与雷达覆盖 agent orchestration、durable execution、任务恢复/取消、评测、观测、模型路由、成本控制、重试/熔断、CAS/provenance、browser automation、SSRF/security、MCP/A2A、插件与供应链安全；本轮补充复查约 90 个公开项目，优先 MIT/Apache/BSD、维护活跃且测试充分的仓库。
- 重点来源：
  - [harbor](https://github.com/laude-institute/harbor)：把 agent CLI 整链纳入 Terminal-Bench runner；与 CodeBee 的模型级 evalbench 互补，适合作为远期整链评测参照。
  - [agents-shipgate](https://github.com/ThreeMoonsLab/agents-shipgate)：纯静态能力差异闸门；与 CodeBee 的 skill 扫描、白名单和安装后冒烟同向，暂不重复接入。
  - [sentrux](https://github.com/sentrux/sentrux)：运行中质量传感器；CodeBee 已有评审分数和教训回流，差量是实时反馈，暂列远期观察。
  - [Mastra commit f95b8fa](https://github.com/mastra-ai/mastra/commit/f95b8fa)：连续工具审批恢复时先持久化新标签，提示需审计本地审批状态与快照写入顺序；当前 CodeBee 未发现同构竞态。
  - [OpenAI Agents commit b3d5c1d](https://github.com/openai/openai-agents-python/commit/b3d5c1d)：Redis 清理前校验键类型；CodeBee 无 Redis 会话后端，不移植。

## 二、全类型核对

按 `flows.py` 当前实际注册核对 17 类：`direct`、`code`、`novel`、`serial_novel`、`article`、`video_script`、`doc`、`translation`、`rank_scan`、`defect_retro`、`research`、`speech`、`weekly_report`、`email`、`tech_proposal`、`resume`、`bid_doc`。菜单图标、英文 i18n、内容契约和辅助信息均有对应定义；未擅自增加演示文稿类型。代码关注评审/测试，小说关注一致性，文章/视频关注移动端排版，翻译关注质量，对话/直接执行关注会话复用，邮件/汇报/方案/调研/知识库按各自契约核对。

## 三、七专项结果

- **A Token**：预算熔断、token_meter、三段压缩、cascade、经验召回、会话复用、diff 评审、分级评审提示均在位。工具结果统一压缩、语义缓存、按 diff 深度分级仍是待深挖方向；本轮无足够证据安全新增。
- **B 插件市场**：六源市场、装前白名单/SSRF 扫描、安装后冒烟均在位。新市场项目与现有能力重合高，且多需二跳解析，三问不通过，维持雷达。
- **C 任务类型**：17 类菜单、参数、契约和图标守卫复核通过。
- **D 经验库**：沿用“他们有、我们没有、确实好用”三条件；本轮没有可合并的新方法论，待深挖项维持去重。
- **E 新 CLI**：目录与本机探测复核；未安装候选不盲接，避免死链。
- **F 禅道**：定时扫描、自动建修复任务、合并/resolve、评论回写、通知和设置页路径存在；当前 `poll_enabled=false` 属用户配置，未判故障。
- **G 产品**：未发现新的断链、过时数量文案或图标缺失。

## 四、代码落地判断
