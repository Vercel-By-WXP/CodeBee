## 20:23 WorkDSH 深度调研（用户点名·A1 深挖同款）

**标的**：techflag/workdsh（69★，2026-09-10 建仓，当日仍在推）——基于 DeepSeek Harness 的插件化 Web 工作平台，TypeScript/Cordis 插件体系；「Give AI a job. Watch it work. Open the result.」；明确以 WorkBuddy/CodeBuddy 为产品体验参照（同形态且也做竞品审计）。与我们的同构点：Web 编排台 + dsh CLI 通道 + 技能市场 + 项目/任务/成果闭环；差异点：单上游（dsh）插件化 vs 我们多 CLI 编排单体。

**可借鉴清单（按价值排序）**：

1. **反伪装完成文化（最值得抄）**——全仓「X 不代表 Y」边界声明成体系：进程退出码 0≠插件 ACTIVE、工具列出≠服务健康、Shell exit 0≠无超时、interrupt 接收≠子任务停稳、目录可见≠授权、MentionRef≠通知送达、README 明言「专家团标签≠多智能体在执行」；STATUS.md 2000+ 行每条变更都带「未验证范围」声明（未执行真实模型/未提交/未发布）；许可证表有 dependenciesWithoutDeclaredLicense 诚实缺项栏。对照我们自己的病史（假未达标/假排队/aider 退出码 0 冒充 done/kimi 静默退出）：状态台账的「未验证范围」栏 + 产品面「动画/徽章≠执行事实」审查值得例行化。
2. **不可变修订引用（ADR-0010）**——发布即冻结：preset 发布生成内容摘要/单调修订号 ID，历史任务钉死修订，被引用修订禁物理删除，恢复前校验摘要+健康，漂移则阻止执行给明确诊断而非静默回退默认。对我们的 flows-*.json 热更是直接解法：run 快照记流程 digest，resume 校验不匹配即诊断不静默换新；经验库/技能同理（改技能不断跑中任务的行为）。
3. **ResolvedExecutionBinding 快照**——任务创建时落一份不可变解析结果（精确 provider/model/reasoning effort/技能修订/工具可见性/运行策略），「模型目录只是发现信息，解析结果才是权威」；「显式指定但不支持的推理强度必须在 provider I/O 前拒绝，不静默降级」。我们步骤日志头审计行（-m/-c）可升级成 run 级绑定快照——deepseek 实服 gemini 漂移案本可用它直接对账。
4. **执行事实 vs 业务事实分界（ADR-0012）**——Session=追加式执行事实唯一源（消息/工具/步骤/子代理），业务域（待办/自动化规则/资产修订/审批）各自持有；「原生 todo/schedule/deliverables 近名事件不得冒充业务对象」；业务写入失败不回滚执行事件，展示待对账状态+幂等修复。与我们 run.json/steps 日志/记账行守卫同构，可借它的「近名事件≠业务对象」清单法防新的静默混淆。
5. **取消结算六态**——子代理结算区分 completed/partial/cancelled/failed/unavailable/quiescenceUnknown，取消回执只证「请求被处理」。我们强杀链已修，但终态分类学可补 quiescenceUnknown（杀后无法确认停稳）这档。
6. **发布工程**——release=manifest+SHA256SUMS+安装器 --dry-run+钉死传递版本；「安装器打印 Profile 本地 CLI 命令，避免全局 CLI 混不同运行时」——正是我们 npm 升级旧进程滞留/0.1.63 坏包的结构性预防；HEAD worktree 发布法（第五十班已落地）+ 清单校验可叠加。
7. **契约纪律**——跨插件只传「领域+稳定 ID+修订」引用不传内部对象；稳定 `<domain>/<reason>` 错误码（客户端按 code 分支不靠错误消息）；写操作普遍 expectedRevision CAS。我们 store 层写接口多为 last-write-wins，settings/tasks 可试点。
8. **证据链**——每项验收配 docs/evidence/*.md+可重复探针脚本（scripts/probe-*.mjs）+截图；ADR 带「验证依据」节。borrow-log 已记 commit，可补探针脚本链接位。
9. **产品向·可编辑成品**——「真任务应暴露过程并以可编辑产物收尾」：docx(Tiptap)/pptx(pptx-viewer)/xlsx(Univer)/PDF 浏览器内编辑工作副本+AI 可见编辑态（ADR-0024），依赖选型可抄（全开源 MIT/Apache）。我们网页预览已覆盖 HTML，Office 编辑是方向储备。
10. **输入引用修订**——任务输入引用资产精确修订而非可变 latest；跨会话引用=有预算的时间点快照。我们 _attachments 可加内容 digest，断点续跑时校验完整性。
