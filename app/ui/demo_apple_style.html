Apple-style 改动清单

1. 去硬边 → 阴影纵深

所有 1px border 换成多层 box-shadow（0.5px + 2px + 8px 三层），卡片像浮在背景上。

2. 大圆角

卡片 16→20px、按钮 10→12px、对话气泡 18px、输入框 14→22px。更圆润柔和。

3. 毛玻璃

顶栏 + 侧栏 + 输入条加 backdrop-filter: blur(20px) saturate(180%)，半透明磨砂质感。

4. 弹性过渡

所有 transition 从 linear/.15s 改成 cubic-bezier(0.25, 0.46, 0.45, 0.94) + 0.2s，苹果弹簧曲线。

5. 排版柔化

font-weight 700→600/500、letter-spacing 加负值（-0.01~-0.02em），更像 SF Pro。

6. 半透明边框

border 从实色改成 color-mix 50~60% 透明度 + 0.5px 细线，边界若隐若现。
