保留

  • 首页总览：在跑 / 待处理
  • 一键发新任务
  • 裁决：通过 / 驳回
  • 任务详情：进展 + 产出
  • 补充说明 / 纠偏
  • 暂停 / 重试 / 归档
  • 完成通知
  • 连接 / 外观 / 语言

  • 运行记录 Tab（并入任务）
  • 完整设置树
  • 专家启动面板
  • 工作区分组折叠
  • 详情 8 个分区
  • 原始日志 / Git 区
  • 批量选择 / 删除
  • 汉堡抽屉导航

需要你拍板

  1. 详情只留「进展 / 产出」两段，原始日志和 Git 细节回电脑看 —— 够用吗？
  2. 输入区保留「附件 + 语音」，还是只留文字更干净？
  3. 手机设置只留连接、外观、语言、通知，其余配置回电脑 —— 可以吗？

取舍：手机不再是缩小的桌面。代价是手机上处理不了分支裁决细节和完整日志；需要时给「在电脑上打开」的明确提示，不做假入口。
