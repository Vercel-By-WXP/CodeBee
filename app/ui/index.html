钩子

          

            
          

        

        
在任务生命周期的关键点执行本机命令：命令从标准输入收到 JSON（事件与任务上下文），标准输出回 {"inject": "文本"} 即把文本注入提示词（run_end 的输出被忽略，适合回写知识库）。命令按空格分词执行，不支持管道；失败或超时自动跳过，绝不挡主流程。

        

        
还没有钩子——点「新建钩子」在任务开始 / 消息送达 / 运行结束时挂你自己的脚本。

模型调度（可选）

            
            
            
          

          
默认无需绑定：CodeBee 会按任务类型、步骤角色、难度、成本、协议兼容性和健康状态动态推荐厂商与模型，并在无可用供应商时回落 CLI 自身配置。只有需要固定厂商、模型或跨厂商降级顺序时才在这里指定；显式指定会覆盖自动推荐，但不改写 CLI 全局配置。

          

        

      


      
      

        

          
经验库

            

          
系统自己的经验沉淀：内置规范包（如七猫签约标准，自动注入小说类任务的规划与评审提示词）
            与运行中自动学到的教训（每次任务结束由编排者复盘本次评审暴露的问题，去重沉淀，下次同类任务自动带上）——越跑越好，无需人工维护。

知识库

            

          
运行产出自动整理成的可复用知识：任务结束由编排者从产出材料自动提炼，默认直接转正参与注入；也可以手动新建——同时是你自己的知识管理库。条目按任务类型与相关性自动注入同类任务的规划与评审提示词。

          

            
            

          

          

          
知识条目 

          

        

      


      
      

      

        

          
插件市场

          
          
        

        
用经验包为 CodeBee 扩展写作与工程守则，一键装进经验库。安装即生效，无需手动调用：运行任务时，经验库按插件标注的「适用」自动把内容注入该类任务的提示词；可随时到「经验库」页启用、停用或卸载。

        

          
          
        

        

        

          
          
          

            
            
            
          

        

        

        

        

          
外部目录聚合公开生态：ZCode、Anthropic、Anthropic 官方技能、社区多端技能库（Codex / Gemini 兼容）与 ClawHub。本平台只注入纯技能内容（文档型）；插件包里的脚本、钩子或 MCP 组件会在安装时自动剥离并告知，绝不会被写入或执行。装好的技能不会单独「运行」，而是作为经验内容自动注入相关任务的提示词。

          

            
            
            
            
          

          

          

          

            
            
          

          

        

      

      


      
      

        

          
编排设置

          
「编排者」是 CodeBee 自己的智能体：直连 API 供应商的模型（不占 CLI 会话），统一负责任务规划拆解、难度判定与写作大纲。未启用或调用失败时自动回落为「最强可用 CLI 智能体」规划，流程永不阻塞。

          

          
运行设置

          

            

              
              
            

            
编排类任务按此上限执行，满载自动转入「排队中」并每 15 秒尝试补跑（最长 10 分钟），不判失败。此上限保护的是本机资源（CLI 子进程数），与各 API 厂商的限流无关——多厂商并行不必为厂商额度调大它；direct 对话走独立轻量通道，不占此额度。自动续跑的退避等待不占执行位。

          

          

            

              
              
              
            

            
            

          

          

            
            
开启后 CodeBee 会覆盖 cc-switch 等工具对交互 claude 的手选配置。关闭后交互 claude 配置归你手动管理；编排步骤改用一次性注入，模型路由不受影响。

备份与搬家

            
          

          
换电脑或换路径安装时，把全部数据打包带走：模型/密钥/绑定等全部配置、任务与运行记录、经验库、知识库、发布台账，以及各任务工作目录里的手稿与成品文件。导入时自动把旧机器的路径改写成新机器的路径。

          
注意：备份包含 API 密钥，请妥善保管；发布平台的浏览器登录态不在备份里（体积 GB 级），导入后发布时需重新扫码。不在默认保存路径下的外部目录（如单独指定的代码仓库）不会打包，导入后会在预览里点名提醒。

          

            
            

              
              
              
            

            
            

          

        

        

          
恢复（导入备份包）

          
选择之前导出的备份包，先预览确认再导入。导入会覆盖同名任务与配置；当前数据会先自动备份一份到数据目录 imports/ 下，导入后需重启服务生效。

          

            

              
              
              
            

            

              
              
            

            
合并导入：保留本机现有数据，备份包里的同名条目覆盖进来。替换导入：先清空本机数据目录再整体落入（宠物锁与历史导入备份除外）——只在想把新机器变成备份包原样时使用。

            
            

            

              
              
            

          

        

        

          
每日清理

          
每天自动清理运行过程日志、发布截图、配置备份残留等可再生数据（保留运行记录与结果报告），防止磁盘越积越满。手稿、任务记录、经验库等用户数据永不清理。

          
          

            
            
            
            
          

          

          

          

            
          

        

      


      
      

        

          
关于与更新

          
加载中…

          

            
            
            
            
          

          

          

          
升级会通过 npm 拉取最新版并自动执行（日志可在运行记录里实时查看）；完成后点「重启服务生效」，页面会自动重连。开发仓库（git clone）模式不提供自动升级，请用 git pull。

          
帮助改进 CodeBee

          
          
只上报失败原因码、供应商/模型名与脱敏后的错误摘录——绝不上传任务内容、章节正文、API 密钥和本机路径；关闭后立即停止一切上报。

          

            
            
          

          
生成一个 zip（近 30 天错误记录 + 用量统计 + 版本环境信息，已剥离敏感数据），反馈问题时可附在 Issue 里。

          
端口占用

          

            
          

          
谁占着端口、属于哪个项目一目了然；「仅本机」的端口外网不可达。关闭只发温和信号，系统进程与本服务自身拒绝关闭。
