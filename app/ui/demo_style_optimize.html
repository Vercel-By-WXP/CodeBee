2. 主按钮：扁平化

当前版本（渐变 + 高光）
问题：135° 渐变 + inset 高光 + 外发光，视觉元素过多。2026 年主流设计趋向扁平 + 微阴影。
优化版本（纯色 + 微阴影）
改进：纯色背景 + 1px 微阴影，hover 时变亮 + 上浮 1px。视觉重量降低，交互反馈更清晰。

4. 滚动条降噪

当前版本（主色调）

这段内容用于演示滚动条样式。当前版本的滚动条使用 22% 主色调混合，视觉上较为突出。

滚动条是辅助控件，不应抢占视觉焦点。主色调滚动条在浅色皮肤上尤其显眼，容易分散对内容的注意力。

特别是在多行代码或长文本场景下，高饱和度的滚动条会形成视觉干扰。

问题：全局主色调滚动条过于显眼，辅助控件抢焦点。
优化版本（中性色）

这段内容用于演示滚动条样式。优化版本使用 30% 中性灰混合，视觉上更低调。

滚动条退居幕后，内容成为焦点。hover 时加深到 50%，交互反馈仍清晰。

中性色滚动条在所有皮肤下表现一致，不随主色漂移。

改进：滚动条改用 30% 中性灰，hover 50%。辅助控件降级，内容优先。

总结

  • 对话区卡片化 — 智能体回复加浅底，层次更清晰
  • 按钮扁平化 — 去渐变去高光，符合 2026 设计趋势
  • Composer 紧凑 — 减少 30% 空白，提升首屏密度
  • 滚动条降噪 — 辅助控件降级，内容优先
  • 健康横幅低调 — 警告在但不刺眼
  • 侧栏指示明确 — 左边框 + 浅底，区分度提升

以上优化均基于现有 CSS 变量体系，改动量小、风险低。如认可方向，可逐项落地到 style.css 的 2026 refresh 层。
