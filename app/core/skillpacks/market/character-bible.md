# 角色小传与人物弧光模板（市场包）

适用：开书前建角色档案、连载中防人设漂移。与平台流量包互补：流量包管
「读者为什么追」，本包管「人物为什么可信」。人设崩塌带来的流失不可逆——
评论区第一次出现「OOC」「崩人设」时，掉的数据基本回不来。

## 一、小传模板（有名有姓的角色都建档，配角用精简版）
- **基本档案**：姓名 / 年龄 / 身份职业 / 外貌。外貌只挑 ≤3 个**有辨识度且可反复
  使用**的特征（疤、跛、口音、总戴手套），不要「很帅」「很美」这类无法复用的词。
- **表层目标**：TA 自己以为想要的东西（金银、复仇、上岸）。
- **深层需求**：真正缺的东西（认同、安全感、被看见）——弧光的终点就是发现并得到它。
- **恐惧与软肋**：最怕失去什么；软肋必须**情节可攻击**（有家人的反派才有戏可写）。
- **创伤与信念**：一句成型的信条（如「强才能活」），角色一切非常规行为的解释源头。
- **语言指纹**：口头禅 / 句长习惯（文绉绉还是粗短句）/ 禁用词（读书人不说粗话）/
  称呼习惯（怎么叫主角）。这是对白区分度最硬的抓手。
- **关系网**：与主要角色的关系各一句话 + 张力在哪（靠什么维系、因什么会破裂）。

## 二、弧光规划（主角必须有，重要配角推荐）
- 四拍结构：**起点状态**（用旧信念应对世界）→ **触发事件**（旧信念失灵的一击）→
  **中间摇摆**（至少两次反复：尝试改变，再退回舒适区，不许直线转变）→
  **终点状态**（新信念，且由高潮事件证明成立）。
- 弧光要「可拍摄」：终点状态必须体现为**行为变化**（以前遇辱必怒，现在能先忍住
  查真相），不能靠内心独白宣布「他长大了」。
- 反派同样要逻辑自洽：反派在自己的故事里是合理的（有目标、有原则、有能力），
  **反派不无脑**；反派降智 = 主角胜利贬值 = 全书爽点贬值。

## 三、防崩纪律（连载中执行）
- 写对白前回看该角色的「语言指纹」；**遮名测试**：不同角色的对白遮住名字能认出
  是谁说的，认不出 = 语言指纹失败，回去改。
- 配角也要「想要什么」：出场就带着自己的目的行动，哪怕只写一句。
  只在剧情需要时才动的工具人，是群像发糊的根源。
- **每 10 章回看小传**：外貌、伤势、随身物、人际关系与正文逐一核对——伤过的手
  不能无解释痊愈，卖掉的东西不能再掏出来。
- 能力升级必须有过程与代价；「突然会了」读者瞬间就能感知。
- 人物相关设定要改，必须回填小传并排查前文旧描述（与一致性台账守则联动）。

## 四、配角精简模板（三行建档）
- 一句话身份 + 此刻想要什么（出场动机）。
- 一个可复用的辨识特征（外貌 / 口头禅 / 习惯动作）。
- 与主要角色的关系张力（靠什么维系、因什么破裂）。
三行都填不出来 = 这个角色还不该出场；信息攒够再让他登场。

## 五、小传模板示例（可直接复制）
> **姓名**：xxx　**年龄 / 身份**：xxx
> **表层目标**：……　**深层需求**：……
> **恐惧软肋**：……　**信条**：……
> **语言指纹**：口头禅……；句式……；禁语……
> **关系网**：与主角——……；与反派——……
> **弧光四拍**：起点…… → 触发事件…… → 摇摆…… → 终点……

## 六、写作前自检
- [ ] 本章每个出场角色都知道自己「想要什么」，行为在为目标服务
- [ ] 对白符合各自语言指纹（遮名测试通过）
- [ ] 主角行为符合当前弧光阶段：没提前顿悟、没无铺垫地反复横跳
- [ ] 反派行为在其自身逻辑内成立，没有为剧情方便而降智
- [ ] 外貌 / 伤势 / 随身物与前文一致，本章新信息已记入小传
