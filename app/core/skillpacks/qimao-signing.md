## 〇、平台底层逻辑（先懂平台再动笔）
- 七猫 = **免费阅读**平台：收入靠广告分成 + 保底，读者要"即时爽"，不是付费站的"大悬念勾追读"。
- 调性叫**"无线风"**：节奏比起点快、情绪比新媒体文稳、全程围绕爽。错配文扫开头 300 字就被 pass。
- 主收题材——女频：总裁、宅斗、种田、年代、玄幻；男频：都市、玄幻、历史、系统文。
- 核心公式：**网文本质是提供情绪价值（爽/虐/共情），以期待感为导向**。过稿 = 抓住主流读者情绪，
  让读者代入、爽、乃至共情。
- 工作观："你不是在写一本书，而是在经营一个产品。""方向>努力，结构>文笔，情绪>逻辑。"

## 一、黄金一章（一章定生死）
老编辑看第一章就能定过不过——**黄金三章已进化为黄金一章**：一章内展现以前三章的信息量。
- **前 100 字**：主角登场，读者知道故事围绕谁。
- **前 200 字**：已出现值得关心的异常、欲望或冲突。
- **前 600 字**：眼前困境具体（退婚/背叛/陷害/侮辱/破产/误会/灾难/生死危机），不再铺垫。
- **前 2000 字**：核心吸引点已实际展示（字数位置本身不证明吸引力）。
- **第三章前**：主线明确（主角要干什么，像"鸣人要当火影"一样清楚）。
- 第一章具名人物尽量少（五人可作阅读负担参考）；前三章要有实质局面变化；
  反转必须由前文条件引发，不为口诀机械加死亡/背叛。
- 标准开篇节奏：**第一章立冲突+结尾小钩子 → 第二章亮金手指+明确短期目标 → 第三章第一次爽点/打脸**。
- 三幕式开头：开端（置于巨大危机）→ 发展（金钥匙出现，开始反杀）→ 反转（幕后推手/新一轮追杀/新功能/好友捅刀）。
- **开篇禁忌**：不堆设定、不铺世界观、不大段环境描写、不集中抛人物关系；不写无用剧情；
  不玩倒叙花样；配角戏份不得压过主角。
- 用对话开场最有效（悬念式/劲爆式/仇恨式）；行文"短平快"，写小说不是说明文。

## 二、爽点、期待感与钩子
- **每章至少 1 个爽点或情绪爆点**，过渡章也要有小冲突小爽点；**三章一小爆，十章一大爆**。
- 爽点要及时：忌主角第一章 1 级第十章还是 1 级。最简公式：**定个目标 → 完成它**。
- 爽点 = 欲扬先抑：**"不是主角因为要被欺负而被欺负，而是主角为了爆发而被欺负。"**
  打压必须有明确动机；打脸爽不爽取决于**反派心理变化**的描写。
- **期待感三源**（掌握一种就够用）：① 信息差（读者知道、主角/对手不知道）；
  ② 目标预告（"三年之约"式，读者等着看那一幕）；③ 悬念伏笔（小伏笔=断章钩子；大伏笔有伏必应）。
- **每章结尾必留钩子**：断章、说话说一半、章尾挖坑、反转预告。免费站**章尾小爽点比大悬念更管用**。
- 前期不断挖坑：神秘人暗中观察、有人准备下套、看似好人实则利用。

## 三、主线与节奏
- 一句话主线 + 主角目标细化；目标不细化 = 过程流水账。
- **与当前重点无关的一律不写**；每章自问："这章结束，剧情有没有往前挪一步？"没有就删改。
- 书的循环本质："起承转合无限循环，一波未平一波又起，**主角永远处于麻烦之中**。"
- 小剧情单元：目标→行动→阻碍→反转；大剧情链：起因→发展→转折→高潮→结局。
- 同一件事不重复叙述；背景设定拆散夹在剧情里带出。
- 分清剧情流/感情流，笔墨按类型分配。

## 四、人物（红线）
- **主角主观能动性是红线**：必须主动触发、推动剧情；全程被推着走 = 拒稿级致命伤。
- 男频毒点：优柔寡断、不杀伐；不能当舔狗（舔必须有原因有好处且写出暗爽）。
- **反派要有心机有手段，不能无脑**；配角要有动机。
- 人设四要素：基础设定、个性化标签（口头禅/小习惯）、反差萌、人物弧光。
- **人设不崩是底线**；人设变化需要铺垫。

## 五、视角与文笔
- **故事必须从主角视角展开**；上帝视角 = 读者找不到重点。
  例：×"昏暗的房间里，一个男人把南笙按在沙发上" → √"好痒……南笙迷迷糊糊苏醒，感觉腿上一阵瘙痒，
  随后一只粗糙的大手便摸上了她的大腿"。
- 开篇即入主角视角，不用旁白自我介绍；读者未对主角产生好感前，不铺大篇幅受伤/惨状。
- 避免直白叙述："她哭得很伤心" × → "她蜷缩在墙角，指甲掐进掌心，喉咙里溢出压抑的呜咽" √。
- 用最少的文字描绘最真实的画面，追求"准确"；心理描写用动作替代；对话要有信息量。
- 段落短，适配手机阅读；少错别字病句。

## 六、题材、书名、简介
- 题材 = 个人兴趣 × 市场需求的最大公约数；风格要匹配题材。
- 微创新四法：职业创新、关系错位、背景迁移、热梗叠加（分主次）。
- 书名带情绪、有看点、有关键词；忌文艺含蓄无信息量。
- 简介三要素：背景（身份+处境）+ 冲突（核心矛盾+情绪爆发）+ 悬念（埋钩子）。

## 七、投稿与签约（流程约束）
- 直发（推荐新人）：**满 2 万字申请签约评估**，满 3 万字可发布上架；3-5 个工作日出结果。
- 一稿一投，不海投；超 7 天未果主动跟进一次；三个编辑都拒 = 写新稿。
- 签约模式：纯分成 / 保底+超保底分成 / 超级纯分成。
- 红线：涉政涉军涉敏低俗、抄袭洗稿、双男主双女主、非独家（外站内容必须全部下架）。

## 八、签约自检清单（写完逐项过）
**开篇（第一章）**
- [ ] 前 100 字主角登场　[ ] 前 200 字出现冲突　[ ] 前 600 字冲突明确
- [ ] 前 2000 字有大悬念或核心矛盾　[ ] 第一章具名人物 ≤ 5
- [ ] 无世界观/环境/背景堆砌　[ ] 主角视角、无上帝视角旁白
- [ ] 开场用冲突/悬念/对话　[ ] 章末有钩子
**前三章**
- [ ] 第二章亮金手指 + 短期目标明确　[ ] 第三章完成第一次打脸/爽点
- [ ] 三章内有反转　[ ] 主线清晰（目标/障碍/要做什么）　[ ] 每章至少 1 个爽点
**全书通用**
- [ ] 主角主动推动剧情　[ ] 本章剧情比上章往前挪一步
- [ ] 打压有动机、反击有铺垫　[ ] 反派有脑子有心理变化
- [ ] 人设未崩、主角果断　[ ] 无重复叙述、无与主线无关描写
- [ ] 细节用动作/神态替代直白情绪词　[ ] 段落短，适配手机阅读
