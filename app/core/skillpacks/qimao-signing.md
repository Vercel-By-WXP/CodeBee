## 证据等级与使用边界（2026-09-30 更新）

- **A级：当前平台事实**：只接受作家助手/合同/官方公告中当前可见的规则；投稿、独家、更新和内容红线必须回到原页面核对，历史材料不能代替政策。
- **B级：多篇经验或明确拒稿原文**：可作为质量诊断假设，必须同时指出正文位置、读者/编辑反馈和可验证的下一步实验；不能写成“满足即过签”。
- **C级：单个作者口诀或未给证据的数字**：只保留为待验证问题，不注入硬门禁，不据此推断签约率、推荐权重或收入。
- 报告按“稿件质量 → 平台适配 → 当前政策”分层。每条结论都写清证据范围、未知项和风险；确定性字数/格式检查只能提示复查，不能替代文学判断。

### 跨平台质量底线

先检查首个故事单元是否有**具体事件、主角主动选择、可见后果、阶段性兑现和新的可追问问题**，再看爽点密度。人物动机、因果连续性、前后设定、文风锚、手机阅读段落和内容安全是独立维度；任何一项未读、未测或仅凭摘要得出，都标为“未证实”。

## 〇、平台定位（经验假设，先核对当前频道）
- 七猫的免费阅读、广告/保底和即时反馈，是选题与节奏的**定位假设**；不同频道、时期和合同可能不同，不能从定位直接推出收入或签约结果。
- “无线风”、热门题材带和“开头很快给到情绪价值”来自历史经验帖，适合拿来设计对照实验；榜单与后台数据优先于口诀。
- 核心问题不是套公式，而是：读者是否迅速知道主角、处境、目标和下一步；本章的承诺是否在正文兑现。
- 工作观可保留为复盘提示：“方向、结构、情绪”分别写成可验证的事件、选择、后果，不把口号当质量结论。

## 一、黄金一章（历史经验观察点，不是“一章定生死”）
资料建议把第一章作为高信息密度取样点；以下位置是阅读负担观察参考，不代表编辑统一标准。逐项记录证据，未满足不等于质量不合格。
- **前 100 字**：观察主角何时登场，读者是否知道故事围绕谁展开。
- **前 200 字**：观察是否已有值得关心的异常、欲望或冲突。
- **前 600 字**：观察眼前困境是否具体（退婚/背叛/陷害/侮辱/破产/误会/灾难/生死危机），而非只铺垫。
- **前 2000 字**：观察核心吸引点是否实际展示（字数位置本身不证明吸引力）。
- **第三章前**：观察主线是否明确（主角要干什么，像“鸣人要当火影”一样清楚）。
- 第一章具名人物尽量少（五人只是阅读负担参考，不是硬门槛）；前三章要有实质局面变化；
  反转必须由前文条件引发，不为口诀机械加死亡/背叛。
- 可复用的一种开篇节奏：**第一章建立冲突并留后续问题 → 第二章让核心能力/设定影响行动 → 第三章完成第一次阶段性兑现**；具体次序服务于本稿题材与因果。
- 三幕式可以作为结构草图：开端（危机/目标）→发展（行动/代价）→转折（新信息/选择），不要求每稿套“金手指/背叛”等桥段。
- 历史经验帖常提醒检查设定、世界观、环境和人物关系是否挤占事件；倒叙、群像或配角戏份本身不是禁写项，重点是读者能否跟住主线。
- 部分经验帖推荐用对话开场（悬念式/劲爆式/仇恨式）；可检查开场是否尽快进入人物行动，不能据此规定所有题材都用对话。

## 二、爽点、期待感与钩子
- 建议复查每章是否有可感知的变化、情绪或兑现；“三章一小爆，十章一大爆”是作者口诀，不能替代逐章判断。
- 部分作者强调及时兑现：可检查目标是否持续推进、阶段结果是否可见，不以等级或固定章节位置判断有效性；"定个目标 → 完成它"可作构思起点。
- 欲扬先抑是可选结构：打压应有情境动机，反击应有铺垫；反派心理变化可作为效果观察点，不要求每个故事都用打脸。
- **三类期待构造方式**（构思工具，不是充分条件）：① 信息差（读者知道、主角/对手不知道）；
  ② 目标预告（"三年之约"式，读者等着看那一幕）；③ 悬念伏笔（小伏笔=断章钩子；大伏笔有伏必应）。
- 建议复查章末是否留下可兑现的下一步问题：断章、说话说一半、挖坑或反转预告均可；“章尾小爽点更管用”只是部分作者经验，需结合读者反馈验证。
- 伏笔不以数量取胜：记录前文铺设、当前承诺和后续回收；神秘人、陷阱或关系反转只有在符合因果并服务本稿时才加入。

## 三、主线与节奏
- 一句话主线 + 主角目标细化；目标不细化 = 过程流水账。
- 复查段落是否推动目标、关系、信息或情绪；若没有可辨认的作用，再考虑删改。休整章节也应有清楚的阅读功能。
- 一种连载经验强调持续制造新局面；可用"起因→行动→阻碍→转折→结果"检查因果，但不要求主角永远处于危机。
- 小剧情单元可用目标→行动→阻碍→结果检查；大剧情链可用起因→发展→转折→高潮→结局规划。
- 同一件事不重复叙述；背景设定拆散夹在剧情里带出。
- 分清剧情流/感情流，笔墨按类型分配。

## 四、人物（经验复查维度）
- 多篇拒稿复盘关注主角是否作出选择并推动事件；检查“目标 → 行动 → 后果”，但不把单一人物类型写成通用过稿红线。
- 部分男频经验偏好果断与强反馈；是否适用取决于题材/人设，避免把复杂人物统一改成“杀伐果断”模板。
- 对手和配角应有可理解的动机与行动；他们不必都强势或聪明，关键是冲突因果成立。
- 人设四要素：基础设定、个性化标签（口头禅/小习惯）、反差萌、人物弧光。
- **人设不崩是底线**；人设变化需要铺垫。

## 五、视角与文笔
- 开篇视角应让读者容易定位人物、信息来源和情绪距离；第三人称全知等视角不是禁项，需看执行是否清楚。
  例：×"昏暗的房间里，一个男人把南笙按在沙发上" → √"好痒……南笙迷迷糊糊苏醒，感觉腿上一阵瘙痒，
  随后一只粗糙的大手便摸上了她的大腿"。
- 开篇即入主角视角，不用旁白自我介绍；读者未对主角产生好感前，不铺大篇幅受伤/惨状。
- 避免直白叙述："她哭得很伤心" × → "她蜷缩在墙角，指甲掐进掌心，喉咙里溢出压抑的呜咽" √。
- 用最少的文字描绘最真实的画面，追求"准确"；心理描写用动作替代；对话要有信息量。
- 段落短，适配手机阅读；少错别字病句。

### 编辑高频驳回话术拆解（实测复盘，动笔/改稿时逐条对照）
以下三条是所汇编材料中反复出现的"文笔类"反馈，可转成自查问题；不代表所有频道或拒稿的完整原因：

- **"风格不够统一"**：叙述语域/句式长短/人称距离在一章内忽高忽低（半文半白 + 网络梗 + 书面长句混用），
  或切场景/切视角时文风跟着变。**修法**：全篇定一个文风锚（如"短句 + 白描 + 口语但不过火"），
  换场不换笔调；网络用语、方言、专有名词只允许一种强度，通篇统一。
- **"不够流畅"**：读出声会卡——长定语/多重倒装、连续多句都以同一主语开头（她…她…她…）、
  动作与反应被拆碎、段与段之间没有承接。**修法**：一句一动作，主谓宾贴紧；
  相邻句换用不同句式与长度；段尾留半句承上启下；写完逐段读出声，卡顿处即病句，就地删改。
- **"细节刻画力度稍弱"**：核心冲突/情绪爆点被一句话带过（该"放慢给特写"的地方按了快进），
  打压—反击缺生理与环境反应，爽点"打不满"。**修法**：每个爽点/反转标记为"特写镜头"，
  用五感 + 微动作 + 环境反馈把这几秒写"厚"（心跳、指节、周围人的呼吸与目光），
  铺垫在前、放大在中、余波在后；场景篇幅按叙事重要性调整，不把"特写"固定套给每个爽点。

## 六、题材、书名、简介
- 题材 = 个人兴趣 × 市场需求的最大公约数；风格要匹配题材。
- 微创新四法：职业创新、关系错位、背景迁移、热梗叠加（分主次）。
- 书名带情绪、有看点、有关键词；忌文艺含蓄无信息量。
- 简介三要素：背景（身份+处境）+ 冲突（核心矛盾+情绪爆发）+ 悬念（埋钩子）。

## 七、投稿与签约（历史流程，提交前必须回后台核实）
- 经验材料常见“2 万字/3 万字/3-5 个工作日”等节点，只能作为项目排期提示；当前频道的字数、审核时长和可投稿状态以作家助手页面为准。
- 一稿一投、跟进节奏和签约模式是作者经验，不是过签条件；拒稿后保留原文、版本、编辑原话和修改范围，再决定重修、重立项或换稿。
- 红线需按当前公告、合同和频道规则核对：涉政涉军涉敏低俗、抄袭洗稿、版权/独家义务等不能靠内部自检替代平台判断。

## 八、投稿前质量与证据清单（逐项过；非签约保证）
先给每个结论标注“当前规则 / 多源经验 / 待验证”，并记录实际读过的章节范围；没有证据的项目不标“通过”。

**开篇（第一章；字数位置仅作观察点）**
- [ ] 观察主角是否尽早登场、读者能否辨认主角　[ ] 观察异常/欲望/冲突何时出现
- [ ] 观察困境是否具体、核心吸引点是否兑现　[ ] 复查具名人物是否过密（“五人”仅为阅读负担参考）
- [ ] 复查设定/环境/背景是否挤占事件　[ ] 主角视角是否清楚、旁白距离是否符合本稿选择
- [ ] 开场与题材承诺是否匹配　[ ] 章末是否有可兑现的后续问题
**前三章（随题材调整，不强制套章纲）**
- [ ] 核心设定或能力是否改变人物行动　[ ] 是否完成一个有因果的阶段性兑现
- [ ] 是否有局面变化　[ ] 主线目标/障碍/下一步是否可复述
**全书通用**
- [ ] 主角是否作出改变局面的选择　[ ] 本章事件是否推进目标或关系
- [ ] 打压/阻碍有动机、反击/解决有铺垫　[ ] 对手与配角有各自目标
- [ ] 人物变化有铺垫　[ ] 重复信息和与主线无关内容是否影响阅读
- [ ] 情绪表达是否具体且适合本稿文风　[ ] 段落长度是否适配目标阅读场景
- [ ] 每个故事单元都能指出事件、选择、后果、兑现和后续问题
- [ ] 文风锚、因果链、连续性和内容安全分别复核，未把字数/格式当文学评分
