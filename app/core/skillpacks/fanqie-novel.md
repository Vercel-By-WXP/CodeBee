# 番茄小说写作与流量守则（内置经验包）

来源：番茄作家社区与作者群体的通行经验汇编 + 平台公开运营机制（2025）。
签约字数、保底金额、全勤门槛、审核时长等**政策数字随年份调整，一律以「番茄作家后台」当前规则为准**，
本包不固化具体数值。这是写作参考，不是官方规则，也不是爆款预测；不以格式检查推断过签/起量概率。

## 〇、与传统编辑平台的根本区别：番茄是算法平台
- 老牌免费站（编辑审稿制）= **编辑守门**（人审稿定签约）；番茄 = **算法守门**（数据定生死）。
  签约只是门票，签约之后靠完读率/追读率挣流量，才真正决定这本书的死活。
- 读者画像：下沉市场、碎片时间、耐心极低——**弃书零成本**（免费，右上角一点就走）。
  开局漏斗比任何平台都陡：书名 → 简介/标签 → 第一章 → 前三章，每关都在大量筛人。
- 收入模型 = 免费阅读 + 广告分成（读者读得越久、追得越多，广告收益越高），
  叠加签约保底/全勤（若合同有）。所以 **追读率 > 文笔 > 一切自我感动**。

## 一、新书生存线：流量池与数据指标
- 通行理解的机制：新书发布后先进**小流量测试**，按数据逐级放量（书架/推荐/搜索）；
  数据不达标就被限流直至"饿死"。**前 30 天左右的新书期是定生死窗口**。
- 后台核心指标（以作家后台实际展示为准）：**完读率**（本章读完比例，决定能否进下一流量层）、
  **追读率**（读了开头还在追最新章的比例，决定推荐是否持续）、留存、平均阅读时长。
- 数据异常按段落定位病因：第一章完读低 = 开头崩（改开篇）；中段崩 = 节奏/爽点密度不足；
  结尾追读崩 = 断章钩子或大坑久拖不兑现。**不要用"再等等"掩盖结构性问题**。
- 反恐慌纪律：头几天数据小、噪声大，不要 48 小时一改动；到样本足够（约两周）仍差，
  **果断切书开新**——算法平台的沉没成本陷阱比编辑平台大得多。

## 二、开篇（黄金三章，番茄从严）
- 番茄测的是**整前三章**的完读与追读，不是单看第一章：第一章钩人、第二章兑现金手指/核心设定、
  第三章第一个完整爽点闭环，缺一章都撑不起数据。
- 前 100 字：主角 + 具体冲突/异常直接进场；前 600 字：困境压到脸上。
- 开篇禁忌（每条都有对应数据崩法）：世界观说明文（第一章完读崩）、慢热日常（第二章崩）、
  多视角群像（读者找不到主角，追读崩）、倒叙解谜（下沉读者直接弃）。

## 三、节奏与爽点
- **每章至少一个爽点或情绪波动 + 章尾强钩子**；番茄章节奏建议 1800-2500 字/章（短平快，
  卡阅读间隙），别写 4000 字大章考验耐心。
- 主线必须是"一句话能讲清的直线"：目标明确、单线推进、读者永远知道主角下一步要干什么。
  多线叙事、慢热铺垫在番茄大概率数据判死刑。
- 前 100 章要完成一次大爽点闭环（打脸/升级/身份跃迁的大兑现）；过渡章连续两章以上无兑现，
  追读率就会肉眼可见地掉。
- 跨平台通用的铁律仍然有效：主角主观能动性红线、打压为爆发服务、反派不能无脑。

## 四、题材、书名、标签与简介
- 番茄大盘热门题材带（男频）：都市高武/都市脑洞、历史穿越、玄幻、悬疑脑洞（民俗/规则怪谈系在此，
  守村人这类民俗悬疑素材适合往"悬疑脑洞"标签靠）；女频：脑洞言情、年代、萌宝。题材热度轮动快，
  开书前扫一次当季榜单。
- **分类/标签是流量匹配的第一步**：挂错分类 = 推给错的人 = 数据全差且查不出原因。
  书名、简介、标签三者对题材的表达必须一致（算法按这些做人群匹配）。
- 书名策略：长尾、带情绪、带题材关键词；简介三要素：身份处境 + 核心冲突 + 悬念钩子。

## 五、更新纪律（算法平台命门）
- **日更稳定 > 单日爆更**：断更打断追读链，数据直接塌方；全勤/推荐权重普遍与稳定日更挂钩
  （具体门槛看当前合同与后台规则）。
- 存稿 ≥10 万字再发书；新书期若存稿允许，日双更冲数据——推荐系统吃"活跃 + 追读"信号。
- 卡文宁可降纲不降质：拆未来 3 章的单元（目标→行动→阻碍→反转），别水字数糊弄——
  水章的完读率会当场出卖你。

## 六、签约与合同
- 申请门槛（字数）、审核时长以作家后台当前规则为准；常见审核材料 = 开篇正文 + 大纲，
  大纲别只写一句"后面上架爆火"，要有明确的阶段目标与兑现节点。
- 类型以**分成为主**，优质作品可谈保底；签前重点看清 **影视/动漫/版权衍生授权范围**与独家条款、
  违约与切书条款——免费平台合同中 IP 衍生让渡比例是历来争议集中点。
- 拒签自救：先归因（题材带匹配？开篇数据思维？大纲兑现链缺失？），改完再申；
  同一作品反复无修改重投没有意义。

## 七、文笔自查（跨平台通用，2026-09-14 编辑驳回语实证拆解）
- **风格统一**：全篇定一个文风锚（短句+白描+口语但不过火），换场不换笔调；
  文白/网络梗/书面长句不混用。
- **流畅**：逐段读出声——长定语、多重倒装、连续同主语开头（她…她…她…）、动作与反应拆碎，
  卡顿处就地删改；一句一动作，段尾留半句承接。
- **细节刻画力度**：每个爽点/反转标记"特写镜头"，五感 + 微动作 + 环境反馈把爆发那几秒写厚，
  铺垫在前、放大在中、余波在后；过渡章才可一笔带过。**"每章一小爽"不配特写等于没写**。

## 八、开书/投稿前自检清单
- [ ] 书名/标签/简介一致表达题材，分类挂对
- [ ] 第 1 章前 100 字冲突进场；前三章 = 钩子 + 设定兑现 + 完整爽点闭环
- [ ] 每章 1800-2500 字，含至少一个爽点 + 章尾钩子
- [ ] 主线一句话讲得清，单线推进，无慢热铺垫章节
- [ ] 前 100 章有一次大兑现闭环的规划
- [ ] 存稿 ≥10 万字；日更承诺可执行（含请假预案）
- [ ] 文笔三词（风格统一/流畅/细节力度）逐章自查过
- [ ] 合同衍生授权与独家条款已看清
