CodeBee 文档

快速开始

  1. 安装 Python 3.8+ 与至少一个受支持的 AI CLI。
  2. 在仓库根目录运行 python app/main.py --port 8765，默认仅监听 127.0.0.1。
  3. 打开 http://127.0.0.1:8765，在设置中检测并绑定 CLI。
  4. 输入目标，启动编排并在报告页查看步骤、评审与产物。

CLI 配置

CodeBee 不安装、替换或改写第三方 CLI 的全局凭据。请先按供应商文档完成登录，再在 CodeBee 的 CLI 能力页确认可执行文件、版本和模型族。

常见问题

CLI 没有检测到

在终端运行 where code（Windows）或 command -v code（macOS/Linux），确认 PATH 对启动 CodeBee 的进程可见，然后重启服务。

任务卡住

先查看任务步骤和日志；检查 CLI 是否仍在等待登录、额度或人工确认。可安全停止任务，恢复规则会保留已完成步骤。
